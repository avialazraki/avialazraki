## 🚀 Featured Project

### 🏨 [HotelIQ — Hotel Revenue, Demand & Cancellation Intelligence](https://github.com/avialazraki/HotelIQ)

An end-to-end data analytics project exploring hotel booking behavior, cancellation patterns, and predictive modeling.

**Technologies:** Python · Pandas · PostgreSQL · Power BI · Scikit-learn · GitHub

**Project highlights:**

- Analyzed **118,564 cleaned hotel booking records**.
- Built an interactive **three-page Power BI dashboard**.
- Investigated cancellation patterns across hotel types, market segments, and booking lead times.
- Developed a Random Forest cancellation prediction model.
- Achieved **74.90% accuracy**, **73.26% recall**, and **0.8321 ROC-AUC** on the held-out test set.
